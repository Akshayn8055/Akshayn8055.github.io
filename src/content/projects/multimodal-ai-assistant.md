## Overview

Engineered an interactive LLM-based assistant capable of talking, listening, seeing, and maintaining contextual memory across sessions, using Python, OpenCV, Whisper, and advanced LLMs.

## What it does

- Real-time vision input via OpenCV for visual grounding.
- Speech-to-text via Whisper for natural conversation.
- Persistent contextual memory across sessions, rather than a single stateless exchange.
