## Overview

Built an assistive navigation tool for visually impaired users, leveraging real-time object detection (YOLOv8) and text-to-speech to alert users of obstacles and provide navigational instructions.

## What it does

- Processes an Android camera feed on a Python server with **sub-100ms latency**.
- Detects obstacles in the user's path in real time and converts them into spoken navigational guidance.
